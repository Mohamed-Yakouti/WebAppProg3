Code Display: Minesweeper Recursion

The following Java snippet demonstrates the use of recursion to reveal clear tiles in the classic game Minesweeper. When an empty tile is clicked, it recursively checks adjacent tiles to auto-clear surrounding empty spaces. 

public class Minesweeper {
    public void revealTile(int row, int col, boolean[][] visited) {
        if (row < 0 || row >= grid.length || col < 0 || col >= grid[0].length || visited[row][col]) {
            return;
        }

        visited[row][col] = true;

        if (countAdjacentMines(row, col) > 0) {
            return;
        }

        for (int dr = -1; dr <= 1; dr++) {
            for (int dc = -1; dc <= 1; dc++) {
                if (dr != 0 || dc != 0) {
                    revealTile(row + dr, col + dc, visited);
                }
            }
        }
    }
}
